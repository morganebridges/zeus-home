# Home Internet Planning

This folder contains planning documents for upgrading our home internet infrastructure.

## Overview

We're moving away from the basic Xfinity modem/router combo to a more robust networking setup with proper network segmentation and security.

## Planning Components

### Hardware Selection
- **Modem**: Evaluate standalone modems vs. bridging existing Xfinity combo unit
- **WiFi PoE**: Research Ubiquiti devices for our networking rack
- **Rack Integration**: Plan placement and mounting in our small networking rack

### Network Architecture
- **WiFi Networks**: 
    - General internet access
    - Isolated home automation network (locks, IoT devices)
- **VLAN Setup**: Network segmentation for security
- **VPN Configuration**: Remote access planning

### Infrastructure
- Integration with planned k3s deployment on home server
- Rack organization and cable management
- Power and cooling considerations

## Goals

- Improved network security through segmentation
- Better performance and reliability
- Scalable infrastructure for future expansion
- Clean, professional rack installation
